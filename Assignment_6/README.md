Inheritance in C++

This program demonstrates three types of inheritance in C++: Single, Multiple, and Multilevel Inheritance.
Single inheritance allows a child class to inherit properties and functions from one parent class.
Multiple inheritance allows a child class to inherit from two or more parent classes.
Multilevel inheritance forms a chain in which a class inherits from another derived class.
The program uses classes and objects to demonstrate how inherited functions can be accessed.
It helps understand code reusability and the basic concept of inheritance in Object-Oriented Programming (OOP).
