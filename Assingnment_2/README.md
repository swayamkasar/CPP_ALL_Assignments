Student Constructors Program

Aim

To demonstrate different types of constructors and member functions in C++.

Description

This program demonstrates:

- Default Constructor
- Parameterized Constructor
- Copy Constructor
- Member Functions
- Destructor

The "Student" class stores and displays the roll number and name of students.

Concepts Used

- Classes and Objects
- Constructors
- Copy Constructor
- Member Functions
- Destructor

Sample Output

Default Constructor Called
Roll No: 0
Name: Unknown

Parameterized Constructor Called
Roll No: 101
Name: Rahul

Copy Constructor Called
Roll No: 101
Name: Rahul

Default Constructor Called
Roll No: 102
Name: Amit
