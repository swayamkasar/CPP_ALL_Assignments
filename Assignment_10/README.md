Class Template and Function Template in C++

This program demonstrates the implementation of class templates and function templates in C++. The class template "Calculator" performs addition and multiplication using different data types, such as integers and floating-point numbers. The function template "findMaximum()" returns the greater of two values. The "template <class T>" keyword allows the same code to work with different data types. This program demonstrates code reusability and reduces code duplication using templates in C++.
