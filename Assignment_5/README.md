This program demonstrates the use of classes, objects, private and public data members, inline function, this operator , friend class and the `void display()` function in C++. A `Student` class stores the roll number and marks of a student. In the first scenario, private data members are accessed through member functions of the class. In the second scenario, public data members can be accessed and modified directly from the `main()` function. The `display()` function prints the student's details in both cases.
