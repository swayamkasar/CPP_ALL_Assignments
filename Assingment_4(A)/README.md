 Pointers and References in C++
This program demonstrates the use of pointers and references in C++. 
It accepts a student's score as input and displays its original value. 
A pointer is used to store the memory address of the variable and modify its value using the dereferencing operator. 
A reference is then created to the same variable to change its value again. 
This program helps understand how pointers and references access and modify variables in memory.
