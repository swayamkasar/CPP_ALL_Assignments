# STL Vector Container in C++

This program demonstrates the use of the `vector` container in the Standard Template Library (STL).

- Creates a vector of integers.
- Inserts elements using `push_back()`.
- Deletes elements using `pop_back()`.
- Accesses elements using indexing.
- Displays the size of the vector using `size()`.

**Header File:** `<vector>`

**Language:** C++
