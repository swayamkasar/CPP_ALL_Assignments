Operator Overloading Program

Aim

To demonstrate operator overloading using default and parameterized constructors in C++.

Description

This program uses the "+" operator to add two "Number" objects. It demonstrates constructors, operator overloading, and member functions.

Concepts Used

- Class and Object
- Default Constructor
- Parameterized Constructor
- Operator Overloading
- Member Function

Sample Output

Value: 0
Value: 10
Value: 20
After Addition:
Value: 30
