Student Class Program

Aim

To demonstrate the use of a class, constructor, member functions, and destructor in C++.

Description

This program creates a "Student" class to store and display the student's roll number and name. It demonstrates a default constructor and destructor.

Concepts Used

- Class and Object
- Constructor
- Destructor
- Member Functions
- User Input/Output

Sample Output

Constructor called
Enter Roll No: 101
Enter Name: Swayam

Student Details:
Roll No: 101
Name: Swayam
Destructor called
