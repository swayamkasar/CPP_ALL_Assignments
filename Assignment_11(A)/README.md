# STL List Container in C++

This program demonstrates the use of the `list` container in the Standard Template Library (STL).

- Creates a list of integers.
- Inserts elements using `push_front()` and `push_back()`.
- Deletes elements using `pop_front()` and `pop_back()`.
- Displays list elements using a loop.

**Header File:** `<list>`

**Language:** C++
